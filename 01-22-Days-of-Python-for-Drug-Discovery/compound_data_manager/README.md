# Compound Data Manager

## Overview

Compound Data Manager is a beginner-level Python project developed as part of my learning journey in computational chemistry and drug discovery.

The program processes compound names from a text file, removes empty entries and duplicates, and saves the processed results to an output file.

## Learning Objectives

- File handling and text file processing
- Exception handling and error management
- Functions and input validation
- Python modules and imports
- Code organization and separation of responsibilities
- Working with lists and sets

## Project Structure

```text
compound_data_manager/
├── main.py
├── file_handler.py
├── compound_utils.py
├── compounds.txt
└── README.md
```

## How to Run

Run the following command from the project directory:

```bash
python main.py
```

The processed compound names will be saved to `processed_compounds.txt`.

## Scope and Limitations

This project processes compound names as text. It does not validate chemical structures or calculate molecular properties.

It provides a foundation for future projects involving scientific Python and cheminformatics with RDKit.
