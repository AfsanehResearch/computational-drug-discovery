\# Scientific Python



This section contains Python exercises focused on scientific computing and data analysis, building a foundation for computational chemistry, molecular modeling, and drug discovery.



\## Topics Covered



\### NumPy — Numerical Computing

\- Array creation, data types, and initialization

\- Array dimensions, indexing, and slicing

\- Array reshaping and modification

\- Arithmetic operations and element-wise computations

\- Broadcasting and vectorization

\- Basic numerical statistics



\### Pandas — Data Analysis

\- DataFrame creation and column selection

\- Adding, removing, and renaming columns

\- Filtering rows using logical conditions

\- Selecting and updating data with `loc` and `iloc`

\- Detecting and handling missing values

\- Replacing missing values with column means

\- Counting values and calculating proportions

\- Grouping data and performing statistical aggregations



\## Repository Structure



Each Python file is named according to its main topic to make the exercises easy to identify and navigate.



\## Learning Goals



\- Build practical skills in scientific Python.

\- Learn to manipulate and analyze structured scientific data.

\- Prepare for working with molecular properties and chemical datasets.

\- Establish a foundation for computational chemistry, molecular modeling, and drug discovery.
