# Computational Drug Discovery — Roadmap



## Vision



This repository documents a structured, project-based journey toward computational chemistry, computational drug discovery, and AI-driven drug discovery.



The goal is to progress from foundational programming skills to the design, implementation, validation, and scientific interpretation of computational workflows for drug discovery.



The repository serves as both a learning portfolio and a foundation for reproducible scientific research.



## Learning Path



### 01 — Python Fundamentals

Build a strong foundation in Python programming, modular code, file handling, and software development practices.



### 02 — Scientific Python

Develop skills in scientific computing, data analysis, numerical methods, statistics, and visualization using NumPy, Pandas, Matplotlib, SciPy, and Jupyter.



### 03 — Cheminformatics and RDKit

Learn molecular representations, SMILES, molecular descriptors, fingerprints, similarity analysis, substructure searching, and chemical data processing.



### 04 — Drug Discovery Fundamentals

Understand biological targets, ligands, molecular interactions, bioactivity data, structure–activity relationships (SAR), ADMET, and virtual screening.



### 05 — Molecular Modeling

Explore molecular geometry, molecular mechanics, force fields, conformational analysis, energy minimization, and introductory molecular dynamics.



### 06 — Molecular Docking

Learn protein and ligand preparation, binding-site analysis, docking algorithms, scoring functions, pose evaluation, and validation.



### 07 — Schrödinger Suite

Apply relevant Schrödinger tools to molecular preparation, docking, structural analysis, and selected molecular modeling workflows, subject to software access.



### 08 — AI/ML for Drug Discovery

Develop skills in QSAR, machine learning, deep learning, molecular property prediction, graph neural networks, molecular transformers, and generative molecular design.



### 09 — Integrated Computational Drug Discovery

Integrate cheminformatics, bioactivity analysis, predictive modeling, virtual screening, docking, and molecular property assessment into a scientifically justified workflow.



### 10 — Research Project and Scientific Report

Conduct an independent computational research project, analyze and validate results, document limitations, and prepare a reproducible scientific report or manuscript where appropriate.



## Core Principles

* Learn progressively through practical exercises and projects.
* Preserve scientific rigor and critical interpretation.
* Use reliable, documented data sources.
* Validate computational methods using appropriate benchmarks.
* Prevent data leakage and evaluate model uncertainty.
* Maintain reproducibility through documented code, parameters, and dependencies.
* Distinguish computational predictions from experimental evidence.
* Expand the repository incrementally as new skills and projects are completed.



## Repository Structure

The repository is organized around the ten learning stages, supported by a root README, this roadmap, and shared documentation where needed.



Existing directories and filenames should be preserved unless a deliberate restructuring is justified.



Future directories will be created as their corresponding stages begin.



## Progress Philosophy

Progress is measured by demonstrated understanding, implemented exercises, validated results, and documented projects—not by elapsed time alone.



Each stage should have clear learning objectives, practical outputs, and completion criteria appropriate to its scope.



## Final Objective

Develop the ability to formulate a meaningful computational drug discovery question, select and apply appropriate methods, validate and interpret results critically, and communicate findings through reproducible scientific research.



This roadmap is a living document. Its overall learning sequence provides direction, while individual topics, tools, and projects may evolve as the repository develops.
